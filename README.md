# tugas-pemweb

Perbandingan profile.html vs index.html

Fitur / Peran	index.html	profile.html
Fungsi Utama	Halaman utama (landing page / beranda) dari sebuah situs web.	Halaman khusus untuk menampilkan informasi diri / profil pengembang.
Akses Default Server	Otomatis dibuka pertama kali oleh web server (Apache/Nginx) saat mengakses nama domain atau direktori folder.	Harus dipanggil secara spesifik via URL (misal: localhost/praktikum/profile.html).
Isi Konten	Ringkasan navigasi, banner, pengenalan umum web, dan tautan menuju halaman lain.	Detail biodata, riwayat pendidikan, skills, portofolio, dan kontak diri.
